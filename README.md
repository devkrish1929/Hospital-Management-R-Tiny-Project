# Hospital Management and Patient Data Analysis Using R

## About the Project

This is a Tiny Project developed using R Programming and R Markdown for analysing hospital and patient data.

The project demonstrates data importing, data cleaning, statistical analysis, categorical analysis, data visualisation, correlation analysis, and interpretation of results.

## Objectives

* Import hospital data using R.
* Understand the structure of the dataset.
* Check missing values and duplicate records.
* Perform statistical analysis.
* Analyse patients by gender, department, disease, and status.
* Analyse treatment costs and hospital bills.
* Analyse hospital stay duration.
* Create graphs and visualisations.
* Perform correlation analysis.
* Interpret the results.

## Dataset

The project uses a synthetic hospital dataset containing patient-related information such as:

* Patient ID
* Patient Name
* Age
* Gender
* Blood Group
* Department
* Doctor Name
* Admission Date
* Discharge Date
* Disease
* Treatment Cost
* Stay Days
* Doctor Fee
* Room Charge
* Medicine Cost
* Total Bill
* Patient Rating
* Patient Status

## Technologies Used

* R Programming

## R Functions Used

Some important R functions used in this project are:

`read.csv()`, `head()`, `str()`, `summary()`, `mean()`, `median()`, `var()`, `sd()`, `table()`, `cor()`, `pie()`, `barplot()`, `hist()`, and `plot()`.

## Project Files

* `Hospital_Management_Tiny_Project.Rmd` — R Markdown source code
* `hospital_data.csv` — Dataset
* `output/` — Generated HTML and PDF outputs
* `graphs/` — Generated graphs
* `requirements.txt` — Required R packages

## How to Run

1. Download or clone this repository.
2. Open `Hospital_Management_Tiny_Project.Rmd` in RStudio.
3. Keep `hospital_data.csv` in the same project directory.
4. Install the required R packages.
5. Click **Knit** in RStudio.
6. Select HTML or PDF output.

## Conclusion

This project demonstrates how R Programming can be used to analyse hospital management and patient data through statistical methods and data visualisation.

The dataset is synthetic and is intended for academic demonstration.
